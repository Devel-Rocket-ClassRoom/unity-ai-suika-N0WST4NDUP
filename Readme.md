## 과제 개요

- 클로드 앱·Claude Code·Unity·Unity AI 사용하여 수박 게임 완성하기
- 진행 방식·도구 조합·작업 순서는 자유
- 미션 완료 마다 강사와 리뷰

## 시작 전 준비

- **GDD(Game Design Document) 작성**
    - AI에게 수박 게임을 조사·정리하도록 시키고, 결과를 본인 기준으로 다듬어 마크다운 형식으로 GDD 작성
    - 이후 모든 구현 의뢰에서 이 GDD를 컨텍스트로 같이 전달 — 일관된 결정 기준이 됨
    - 산출물은 본인 저장소 루트(또는 `Docs/`)에 커밋
- GDD 권장 항목
    - 게임 개요 — 한 줄 요약 + 코어 루프
    - 핵심 메커닉 — 떨어뜨리기·충돌·머지·게임오버
    - 과일 단계 — 종류 수·합쳐지는 순서·크기 비율
    - 점수·승패 규칙
    - 화면·UI 구성 — 어떤 정보를 어디에
    - 톤 & 분위기 — 색감·아트 방향·BGM 느낌(자유 구현에서 참고)
- **출발선 점검** — `.claude/settings.json` · CSharpier 훅 · Unity MCP 연결 · `CLAUDE.md` 초안

## 필수 미션 3개

필수 미션 3종

### 미션 1 — 메인 메커닉

- **목표** — 떨어뜨리기·충돌·머지·게임오버 라인이 한 흐름으로 동작
- **완료 조건**
    - 마우스(또는 키 입력)로 과일 한 개를 떨어뜨릴 수 있음
    - 바닥·벽과 충돌해 자연스럽게 멈춤
    - 같은 종류 두 개가 만나면 다음 단계 과일 한 개로 합쳐짐
    - 상단 게임오버 라인 위에 일정 시간 머무는 과일이 있으면 게임 종료 처리
- **자기 점검** — 한 판을 시작 → 진행 → 게임오버까지 끊김 없이 플레이할 수 있는가

### 미션 2 — 애셋 생성·적용 (Unity AI Generators)

- **목표** — Unity AI Generators로 만든 과일 스프라이트가 실제 게임에 적용
- **완료 조건**
    - Generators로 과일 종류별 스프라이트 생성 (GDD에서 정한 단계 수만큼)
    - 결과물 임포트 — 픽셀 단위 정렬·투명도·콜라이더 모양 맞춤
    - 기존 플레이스홀더 도형 → 새 스프라이트로 교체
- **자기 점검** — 플레이 화면의 모든 과일이 직접 만든 아트로 보이는가

### 미션 3 — UI·마무리

- **목표** — 점수·다음 과일 미리보기·재시작 흐름까지 완성
- **완료 조건**
    - 현재 점수가 화면에 표시
    - 다음에 떨어뜨릴 과일이 미리 보임
    - 게임오버 시 결과 화면(점수 표시 + 다시 시작) 동작
    - 빌드(또는 에디터 플레이) 기준으로 한 사이클을 처음부터 끝까지 플레이 가능
- **자기 점검** — 시작 → 플레이 → 게임오버 → 다시 시작 흐름이 한 번에 돌아가는가

## 자유 구현 사항 예시

- **사운드 생성·적용** — 효과음(떨어뜨리기·머지·게임오버) / BGM
- **폴리시·이펙트** — 머지 파티클 / 화면 셰이크 / 진동·피드백
- **밸런스 표** — 과일 단계·등장 확률·점수를 표로 정리해 두고 조정
- **모드** — 시간 제한 / 무한 모드 / 미션 모드
- **연출** — 첫 머지·최종 수박 등장 시 특별 연출
